## 🚀 What I've Delivered

**ERP modernization & billing @ Xsyslab (2023–present)**
- Rebuilt the network billing engine: replaced a risky 3 AM batch with monitored,
  distributed daytime charges — no more DB lock storms, real-time rejection handling.
- Central plan-governance panel with full audit trail for the franchisor.
- In-house Braspag payments dashboard translating acquirer codes into plain language.
- Background jobs (Hangfire), churn/LTV/CAC/MRR analytics, versioned dynamic questionnaires,
  multigateway payment fallback with idempotent webhooks.

**Offline-first dental clinic system (2026–present, in production)**
- Edge architecture: Astro + TypeScript frontend talking to a local Go + SQLite node,
  syncing every 5s; cloud reconciliation to Neon Postgres via **Transactional Outbox**.
- Native Windows launcher (tray) with silent auto-update + rollback for non-technical staff.

**Freelance:** high-conversion retail checkout (Lighthouse 95+), clinic scheduling with
WhatsApp reminders (cut no-shows), multi-tenant feedback SaaS with QR + realtime dashboard.
